# packingsolver_upstream_c

Esta pasta é dedicada aos códigos C/C++ vindos do diretório `src` do repositório oficial:

- https://github.com/fontanf/packingsolver/tree/master/src

Para baixar todo o conteúdo automaticamente para esta pasta, execute na raiz do projeto:

```bash
./scripts_download_packingsolver_src.sh
```

> Observação: nesta sessão, o acesso à rede para GitHub está retornando HTTP 403, então o download automático pode falhar no ambiente atual.
